# Money Log

A personal money app for accounts, spending, budgets, bills and savings, in yen and dollars.
It will run entirely in the browser, hosted on GitHub Pages, like Reading Log. Data stays on your
devices and syncs to a private GitHub repo (`money-data`).

**Status:** planning. See [PLAN.md](PLAN.md) for the proposal, the open questions and the build phases.

This repository only ever holds the app's code: never bank exports, statements or other personal data.
